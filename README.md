# PAJULGAN — Architecture & Engineering

An original vanilla HTML/CSS/JavaScript digital concept website and technical design exploration.

> [!NOTE]
> **Project Status: Conceptual Demonstration**
> 
> PAJULGAN is strictly an architectural and engineering **concept project** and frontend engineering study. It is **not** an active commercial firm, practicing architectural studio, or commercial client site.
> 
> All project names, portfolio pieces (*The Courtyard House*, *The Common Ground*, *Framework / 03*), methodology steps, and engineering specifications presented are purely hypothetical concept studies designed to demonstrate tactile architectural typography, high-performance motion choreography, and zero-framework web craftsmanship.

## Preview

Run `python -m http.server 4189 --bind 127.0.0.1` from this directory, then open http://127.0.0.1:4189.

## Motion

Locally bundled GSAP + ScrollTrigger and Lenis. Curtain entrance, animated original SVG architecture, word-by-word scroll reveal, pinned horizontal project gallery on wider screens, mobile project reveals, structural diagram transforms, section entrances, and continuous scroll progress. Full motion stays enabled regardless of OS motion preference, as requested. Native keyboard and touch scrolling remain available.

## Content and Interactions

Responsive navigation, project detail dialogs, native service accordions, and a validated project brief form that downloads a text file locally. No server, analytics, email delivery, or personal data storage. Connect a real enquiry endpoint and supply verified company details before publishing as a business site.

Project names and descriptions are clearly labeled concept studies, not claims of completed commissions. The SVG pavilion is original. Photos are architectural reference imagery from Unsplash; source URLs are recorded in `assets/sources.txt`. Google Fonts supplies DM Sans and IBM Plex Mono, with system fallbacks. All scripts and photography are local for reliable preview.
